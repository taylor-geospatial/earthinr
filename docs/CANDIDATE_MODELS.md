# Candidate Location Encoders & Watch List

This document tracks geographic `(lon, lat)` location encoders and coordinate Implicit Neural Representations (INRs) that are strong candidates for future integration into **EarthINR** (and `taylor-geospatial/earthinr-zoo`), organized by integration readiness and blocker type.

---

## 1. Missing Pretrained Checkpoints (Code Repo Exists — Ready for GitHub Issue Outreach)

These repositories implement standalone `(lon, lat)` location encoders or coordinate INRs, but do not yet publish pretrained global location-encoder checkpoints (or only publish non-location components). They are ready for polite GitHub issue outreach requesting checkpoint uploads (and license clarification where missing).

| Model | Paper / Venue | GitHub Repository | Architecture & I/O Summary | License | Blocker & Outreach Ask |
|---|---|---|---|---|---|
| **LoCA** *(High priority)* | Koromilas et al., Oct 2026 ([arXiv:2610.32894](https://arxiv.org/abs/2610.32894)) | [eleannavali/LoCA](https://github.com/eleannavali/LoCA) | Two-stage Sentinel-1 + Sentinel-2 + metadata contrastive alignment designed to avoid dimensional/rank collapse; `(lat, lon) -> emb`. | MIT | README states *"Code & pretrained weights coming soon."* Ask for ETA and standalone location-encoder checkpoint release on Hugging Face or GitHub Releases. |
| **Sat2Cap** | Dhakal et al., **CVPRW EarthVision 2024** ([arXiv:2307.15904](https://arxiv.org/abs/2307.15904)) | [mvrl/Sat2Cap](https://github.com/mvrl/Sat2Cap) | `SphericalNet` (`L=30` spherical harmonics + SIREN `location_encoder` + `TimeNet` -> 512-d). | Apache-2.0 | HF repos (`MVRL/Sat2Cap`, `EOS-ITC/Sat2Cap`) only host `CLIPVisionModelWithProjection` (the satellite image encoder); `sat2cap.ckpt` / `location_encoder` weights are missing. Ask authors to upload `sat2cap.ckpt` or stripped location-encoder weights. |
| **FS-SINR** *(Feedforward Few-shot SRE)* | Lange et al., **ICML 2025** ([arXiv:2502.14977](https://arxiv.org/abs/2502.14977)) | [Chris-lange/fs-sinr](https://github.com/Chris-lange/fs-sinr) | SINR-based coordinate encoder paired with feedforward few-shot species distribution encoder (locations + optional text/image). | None specified | Code-only; no pretrained checkpoints linked in repo. Ask for pretrained global location-encoder weights and an explicit OSI license file. |
| **SatCLE** *(Nature Makes No Leaps)* | **WWW / TheWebConf 2025** | [CityMind-Lab/SatCLE](https://github.com/CityMind-Lab/SatCLE) | SatCLIP-style continuous location encoder with stochastic perturbation continuity expansion, graph propagation fusion, and causal refinement on Sentinel-2; `(lon, lat) -> emb`. | None specified | Code-only; no pretrained checkpoints or GitHub releases. Ask authors to release pretrained location-encoder weights and add a license file. |
| **SlepianPosEnc** | Rao et al., **ICML 2026** ([arXiv:2602.00392](https://arxiv.org/abs/2602.00392)) | [arjunarao619/SlepianPosEnc](https://github.com/arjunarao619/SlepianPosEnc) | Regional spherical Slepian basis (`L=40–120`) combined with global spherical harmonics (`L=10`) hybrid + SIREN/MLP. | None specified | Code-only; ROI-specific Slepian basis with no global pretrained checkpoint. Ask whether any global/multi-region pretrained checkpoints or precomputed bases will be released, and request a license file. |
| **Herglotz-NET (HNET)** | Hanon et al., 2025 ([arXiv:2502.13777](https://arxiv.org/abs/2502.13777)) | [TheoHanon/Spherical-Implicit-Neural-Representation](https://github.com/TheoHanon/Spherical-Implicit-Neural-Representation) | Complex Herglotz-map harmonic positional encoding + spherical INR (`pip install spherical-inr`). | Check repo | Code-only (untrained spherical INR architecture). Could be added as an analytic/untrained architecture baseline or tracked if pretrained global checkpoints are released. |
| **CaLLiPer / CaLLiPer+** & **Into the Unknown** | Wang/Liu et al., **CEUS 2025** ([arXiv:2506.02744](https://arxiv.org/abs/2506.02744)) & **SIGSPATIAL 2025** ([arXiv:2506.14070](https://arxiv.org/abs/2506.14070)) | [xlwang233/CaLLiPer](https://github.com/xlwang233/CaLLiPer), [xlwang233/Into-the-Unknown](https://github.com/xlwang233/Into-the-Unknown) | Contrastive coordinate + POI text / spatial-semantic location encoders (trained per city, e.g. London OS POI, FSQ-NYC). | None specified | Code-only; no pretrained checkpoints released and city-specific training setups. Ask if any global or multi-city pretrained weights and a license file are planned. |
| **Space2Vec / Sphere2Vec / TorchSpatial** | Mai et al., **ICLR 2020**, **ISPRS 2023**, **NeurIPS 2024** ([arXiv:2406.15658](https://arxiv.org/abs/2406.15658)) | [seai-lab/TorchSpatial](https://github.com/seai-lab/TorchSpatial), [gengchenmai/space2vec](https://github.com/gengchenmai/space2vec), [gengchenmai/sphere2vec](https://github.com/gengchenmai/sphere2vec) | Analytic multi-scale grid, DFS, and spherical positional encoding families + task-specific MLPs. | MIT (`TorchSpatial`), Apache-2.0 (`space2vec`), None (`sphere2vec`) | No standalone pretrained global checkpoints (analytic PE families only). Candidate for adding analytic `Sphere2Vec` PE baselines to `earthinr.models.encoders`, or requesting pretrained global checkpoints if any are published. |

## 2. Paper-Only / Upcoming Releases (Watch List)

These papers introduce promising global or spatio-temporal `(lon, lat[, t])` location encoders / neural fields, but neither public code repositories nor pretrained checkpoints have been released yet.

| Model | Authors & Venue | Paper Link | Architecture & I/O Summary | Current Status |
|---|---|---|---|---|
| **TIGeR** | Shatwell et al., **CVPR 2026** | [arXiv:2603.24749](https://arxiv.org/abs/2603.24749) | Unified Image + Geo-location + Time encoder using spherical spatial encoding and toroidal temporal encoding (follow-up to GT-Loc). | Project page only (`dshatwell23/tiger.github.io`); code and weights not yet released. |
| **Chronosphere** | Cher, Xing, Li, Wei, Corley & Jacobs, Sep 2026 | [arXiv:2609.21872](https://arxiv.org/abs/2609.21872) | Spatio-temporal neural field on $S^2 \times S^1$ with adaptive space-time tessellation of local climate experts and a shared basis bank; `(lon, lat, t) -> emb`. | Paper-only; no public repo yet (`mvrl/chronosphere` returns 404). |
| **Planetary Feature Fields (PFF)** | Rao, Loeschcke, Shelhamer et al., Sep 2026 | [arXiv:2609.37784](https://arxiv.org/abs/2609.37784) | Hybrid explicit factored feature volume + lightweight per-product implicit decoders modeling multi-product EO data continuously in space and time. | Paper-only; no public code or weights yet. |
| **RevGeoRQ** *(Admin Boundary-Aware LocEnc)* | Oct 2026 | [arXiv:2610.24306](https://arxiv.org/abs/2610.24306) | Self-supervised location encoder trained via reverse-geocoded administrative hierarchy and place names; `(lon, lat) -> emb`. | Code & weights announced *"coming soon"* in arXiv preprint. |
| **MELT / SALT** *(Location Tying)* | **IEEE CASE 2026** | [arXiv:2606.20167](https://arxiv.org/abs/2606.20167) | Multimodal contrastive location encoders (`MELT`, `SALT`) aligning `(lon, lat)` with unpaired geospatial modalities. | Paper-only; no public weights repo found. |
| **TrajGANR** | May 2026 | [arXiv:2605.06990](https://arxiv.org/abs/2605.06990) | Trajectory-centric urban multimodal geospatially aligned neural representation. | Paper-only; no public code or weights found. |

## 3. Regional, Legacy, or Gated Pretrained Encoders (Deferred)

These models have pretrained checkpoints available (or commercially hosted), but are deferred from `earthinr`'s global pure-PyTorch zoo due to regional coverage limits, legacy frameworks, per-tile scoping, or proprietary gating.

| Model | Paper / Venue | Source & License | Architecture & I/O Summary | Reason Deferred |
|---|---|---|---|---|
| **MoRA (`DistilledMoRA`)** | Wen et al., **ICLR 2026** ([arXiv:2506.01297](https://arxiv.org/abs/2506.01297)) | [ylzhouchris/MoRA](https://github.com/ylzhouchris/MoRA) (`pretrained_distilled_model/distilled_MoRA.pth`, 29.2 MB; MIT) | Spherical harmonics (`L=32`, 1024-d) + 8-layer 512-d ReLU MLP distilled from multimodal mobility/POI/satellite/demographics backbone; `(lon, lat) -> 128-d`. | **Regional only** (`ChinaFullSet`); trivially extractable if regional encoders are added later. |
| **CartoVec** | Gursoy, Oct 2026 ([arXiv:2610.17190](https://arxiv.org/abs/2610.17190)) | HF [`gursoyfurkan/CartoVec`](https://huggingface.co/gursoyfurkan/CartoVec) (CC-BY-NC-4.0) | Coordinate encoder trained on structured Overture Maps (land cover/use, transport, places); `[lat, lon] -> 64-d` L2-normalized. | **Regional only** (US Northeast: 11 states + DC), TensorFlow SavedModel format, non-commercial license. |
| **GPS2Vec / GPS2Vec+** | Yin et al., **SIGSPATIAL 2019** & **ACM MM 2021** | [yifangyin/GPS2Vec](https://github.com/yifangyin/GPS2Vec) (Dropbox `models_tag.zip` & `models_visual.zip`; No license) | UTM-zone grid of per-zone Keras MLPs trained on 1M Flickr tags and YLI-GEO visual features; `(lat, lon) -> 2000-d`. | **Legacy stack & license**: Keras 2.2.5 JSON + H5 weights per UTM zone requiring `utm` projection routing and no explicit license. |
| **LIANet / LIANet-MR** | Madadikhaljan et al., **CVPRW EarthVision 2026** ([arXiv:2604.07092](https://arxiv.org/abs/2604.07092)) | [mojganmadadi/LIANet](https://github.com/mojganmadadi/LIANet), HF [`MojganMadadikhaljan/LIANet`](https://huggingface.co/MojganMadadikhaljan/LIANet) (MIT) | Multi-resolution spatiotemporal hash tables + shared CNN decoder over Sentinel-2 archives; `(x, y, t)` per tile -> dense EO features. | **Per-tile regional scope** (e.g., BurnScars / PASTIS tiles) rather than a single global `(lon, lat)` encoder. |
| **Esri Global Location Encoder (S2)** | Esri / ArcGIS Living Atlas (2025) | ArcGIS Living Atlas `.dlpk` (Proprietary) | SatCLIP-based architecture retrained on global 2024 Sentinel-2 L2A (all bands except B10); `(lon, lat) -> emb`. | **Proprietary & gated**: requires ArcGIS Pro organizational credentials and cannot be redistributed in `earthinr-zoo`. |
